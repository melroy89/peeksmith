Peeksmith 1.6.0 is the first release of this continuation of Peek.

- Independent Peeksmith binary, launcher, application ID, settings, and cache.
- GIF, APNG, WebM, and restored MP4 recording with baseline H.264 output.
- Fixes for subprocess hangs, short recordings, cancellation, failure recovery,
  temporary files, GIF quality, save retries, shortcuts, and window placement.
- FFmpeg preferred on X11; GNOME Shell recording preferred on Wayland.

Download the package matching your distribution and architecture from the assets
below. These initial packages target x86-64 (`amd64` / `x86_64`). Install using
`sudo apt install ./peeksmith-*.deb` on Debian/Ubuntu or
`sudo dnf install ./peeksmith-*.rpm` on Fedora. Select only the package for your
installed distribution version. Fedora requires FFmpeg from RPM Fusion for the
x264 encoders; Fedora's `ffmpeg-free` is insufficient for GIF/APNG and MP4.

Checksums are listed in `SHA256SUMS`; verify with `sha256sum -c SHA256SUMS
--ignore-missing`. Checksums detect corruption; these packages are not signed.
A complete source archive is also included.

Peeksmith supports X11 and GNOME Shell Wayland sessions using XWayland. General
native Wayland support is unavailable. GNOME recording depends on the shell's
screencasting interface and PipeWire; desktop availability varies. Existing Peek
preferences are not migrated. Upstream Peek can remain installed alongside it.
