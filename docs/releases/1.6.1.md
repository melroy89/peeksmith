Peeksmith 1.6.1 adds opt-in anonymous GIF sharing, inspired by upstream Peek PR #311.

After saving a GIF, choose **Share last recording…** from the window menu, enter
an Imgur application public client ID and click **Upload to Imgur**. The ID is
saved locally. Never enter a client secret. No upload occurs when recording or
saving; review the recording for private information first.

Uploads support GIF files up to 10 MiB. Copy or open the returned link, and save
**Copy deletion details** privately if you may need to remove the upload through
the Imgur API later. Deletion details are not retained when the dialog closes.
Imgur may convert animations. APNG, WebM and MP4 sharing are not supported.

Uploads run asynchronously, support cancellation and report failures without
terminating the app. Cancelling or losing a connection after sending data cannot
guarantee that Imgur did not receive the upload. Local files are unaffected.

Source builds now require libsoup 3, JSON-GLib and GLib 2.70 or newer. Packages
include the corresponding runtime dependencies and CA certificates.

This is unreleased development work; no 1.6.1 release assets have been published.
