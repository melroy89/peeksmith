Peeksmith 1.6.1 refreshes the build toolchain and packaging dependencies.

- Default MP4 recordings to 30 fps, with a separate saved frame-rate preference.
- Require Vala 0.56, Meson 1.0, GTK 3.24, GLib 2.74, Cairo 1.16,
  and FFmpeg 5.1 or newer.
- Update bundled FFmpeg to 9.0.2 and Flatpak gifski to 1.34.0.
- Refresh Flatpak and Snap runtimes and GitHub Actions dependencies.

Ubuntu packages target 24.04 and 26.04; Ubuntu 22.04 is no longer a release
package target. Debian 12 and 13 and Fedora 44 remain supported package targets.
Choose the x86-64 package matching your distribution. Fedora requires FFmpeg
from RPM Fusion for the x264 encoders.

Verify downloaded assets using the accompanying `SHA256SUMS` file. Packages
are unsigned. X11 and GNOME Shell Wayland sessions through XWayland remain
supported; general native Wayland support is unavailable.
